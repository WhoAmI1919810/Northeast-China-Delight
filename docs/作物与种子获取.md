# 作物与种子获取

> 汇总本模组全部可种植植物与各自「种子」的来路（按 3.1.1+ 源码逐条核对；1.21.1 与 1.20.1 共用同一套数据与代码）。
> 相关实现：`loot/VillageSeedsLootModifier`、`loot/StructureSeedsLootModifier`、`worldgen/*`、`event/ModGameplayEvents`（木耳剥皮、人参刨土）、`villager/ModWandererTrades`、`villager/ModFarmerTrades`、`loot_table/chests/courtyard_*`、`recipe/*_seeds_from_*.json`、`recipe/corn_kernels.json`。

> 2026-10-13（3.0.0）：以下自然获取途径受配置限制。村庄农田由 `worldgen.village_farm_crops_enabled` 与 `worldgen.village_farm_allowed_crops` 控制；箱子由 `chest_loot.enabled` 与 `chest_loot.allowed_items` 控制，二者互不影响。默认全部开启，空列表表示不生成本模组候选；玩家种植、成熟收获、合成、交易和野外植物不受这两组设置限制。完整物品 ID 及中文名见 `自然生成配置.md`。

- **村庄农田**：默认 5 个群系的 13 座农田会按气候长出本模组作物（成熟植株，可直接收割并拿到种子），分配与概率见 `结构生成说明.md` 的「村庄农田里的本模组作物」。

## 2. 逐条途径

### 2.1 战利品箱

**村庄住宅箱**（`village_seeds_*`，平原 / 热带草原 / 针叶林 / 雪原 / 沙漠五张住宅表）：

- 40% 抽 1 次 + 15% 再抽 1 次，每次从 19 项加权池出 1~2 个；
- 另有 15% 出加工品：玉米面 1~3 / 水面团 1~3 / 花生酱 1 / 腌雪里蕻 1~2。

权重池（村庄）：玉米粒 8、大豆 8、大白菜种子 7、雪里蕻种子 5、雪里蕻 4、黄瓜种子 7、青萝卜种子 7、大葱种子 7、荞麦 6、红豆 6、花生 6、青椒种子 6、茄子种子 6、豆角种子 6、红辣椒种子 5、地瓜 5、参籽 2、桔梗 4、桔梗种子 4。

**其他结构箱**（`structure_seeds`，15% 抽 1 次，1~2 个）：沙漠神殿、丛林神庙、掠夺者前哨站、废弃矿井、沉船（补给 / 地图 / 宝藏）、雪屋、海底废墟（大 / 小），以及村庄非住宅箱（盔甲匠、制图师、制箭师、图书馆、石匠、牧羊人、皮匠、神庙、工具匠、武器匠）。池子同上，只有地瓜权重 6。

**东北小院箱**（小院战利品表，NBT 里已挂）：

- 民房 `courtyard_house`：大豆、玉米粒 1~6、大白菜、雪里蕻、雪里蕻种子、荞麦、花生、红豆等；
- 粮仓 `courtyard_granary`：玉米粒 2~8、雪里蕻种子，以及整袋的袋装玉米粒 / 大豆 / 荞麦 / 红豆；
- 厨房 `courtyard_kitchen`：调料为主，另有腌雪里蕻；
- 脱粒仓 `shed_barn` 与部分单体也挂粮仓表。

注：副食店 `relish_*` 五座建筑的箱子没有挂战利品表。

### 2.2 村民交易

- 流浪商人（`ModWandererTrades`）：17 种种子 / 可种子物品 + 榛蘑 + 木耳 + 桔梗本体，各 1 绿宝石 1 个（12 次上限）；人参 48~64 绿宝石，属于稀有池、只卖 1 次。
- 农民（`ModFarmerTrades`）：1 级收大白菜 / 黄瓜 / 青萝卜 / 大葱，2 级卖茄子 / 青椒 / 红辣椒 / 雪里蕻并收 20 个桔梗换 1 绿宝石（16 次上限、5 XP），3 级卖玉米并收玉米茎秆，4 级卖袋装荞麦 12、袋装红豆 14（各 9 个），5 级收袋装大豆 / 花生 / 箱装地瓜等。

### 2.3 自己留种（工作台 / 收获）

- 成熟作物被破坏：掉落产物 + 1 个种子（带幸运附魔有额外加成），玉米另有 1 个玉米茎秆；未成熟被破坏只掉 1 个种子。
- 果实作物（茄子 / 青椒 / 豆角 / 黄瓜 / 红辣椒）成熟时用剪刀右键：摘 1 个果实，植株退回阶段 4 继续长。
- 蔬菜换种（无序合成，1 → 2）：大白菜、雪里蕻、黄瓜、大葱、青萝卜、茄子、青椒、红辣椒、豆角；玉米 1 → 2 玉米粒。
- 袋装 / 箱装：9 个压成 1 袋（袋装玉米粒 / 大豆 / 荞麦 / 红豆 / 花生 / 榛子 / 榛蘑 / 木耳 / 人参）或 1 箱（各种蔬菜），拆开还原 9 个 —— 只是压缩存储，不生新种子。

### 2.4 世界生成

- **野山参**：积雪山坡、雪林（grove）、积雪针叶林、冰封山峰；以 2×2 区块为一个「区域」，30% 概率出 1~3 株，长在草方块 / 泥土 / 灰化土（可带雪盖）。
- **野生桔梗**：森林、白桦林、原始白桦林只在林缘，繁花森林与三种针叶林可整片生成，草甸 / 平原只在靠近森林的交界生成；每区块最多尝试 2 次、每次最多 1 株，半径 4 格内已有桔梗时 92% 失败，因此保持零散。可扎根任意土类方块；周围有草方块、砂土、沙砾、水、农夫乐事沃土时逐类提高概率，8 格内有榛子丛再 +20%。上方直到世界顶必须全无遮挡（树叶也算遮挡），雪层 / 雪块 / 细雪附近和所有雪地群系都拒绝生成。
- **榛子丛**：森林、白桦林、原始白桦林、繁花森林、黑森林每区块 1/6；针叶林、原始松木针叶林、原始云杉针叶林、雪林、积雪针叶林每区块 1/24。
- **榛蘑**：森林、繁花森林、白桦林、原始白桦林、黑森林，每区块尝试 3 次，围着橡木 / 白桦 / 深色橡木树脚撒。
- **木耳**：斧头给原木去皮时掉落 —— 橡木 5%（任意群系）、深色橡木 7%（仅黑森林）、白桦 7%（白桦林 / 原始白桦林）。

### 2.5 人参、榛蘑、榛子丛的特殊收获

- **人参**：直接破坏成熟人参只掉 1~2 参籽，不掉人参；**空手**挖开它脚下那块土 → 1 人参 + 1~2 参籽（手里拿着任何东西都不触发，`ModGameplayEvents#onBlockBreak`）。
- **榛蘑菌落**：把榛蘑种在农夫乐事沃土 / 沃土耕地上，随机刻 1/4 变菌落；菌落右键取 1 个（退回 1 级），剪刀 / 刀可以多取。
- **榛子丛**：成熟（阶段 3）右键摘 2~3 个，未熟（阶段 2）摘 1~2 个，植株退回阶段 1 继续长。

## 3. 备注

- `VillageSeedsLootModifier` 的类注释写「雪原 / 沙漠不出东北作物」，但代码里没有群系判断，且 `village_seeds_desert`、`village_seeds_snowy` 都在 `global_loot_modifiers.json` 里注册了 —— 实际五个群系的住宅箱都会出种子。要按注释来就得补群系条件，否则应改注释（**待确认**）。
- 人参是唯一不能靠手里现成材料补种的作物：参籽只能从野生人参或自己种的人参身上拿。
- 桔梗本体和种子都进入村庄住宅箱与结构箱的同一加权池，并分别写入 `c:crops/bellflower` / `c:seeds/bellflower`；它不参与村庄农田替换，野外生成也不受 `village_farm_crops_enabled` 影响，只有箱子配置会筛选箱子里的桔梗。
- 雪里蕻不是野外作物；成熟收获和箱子是主要种子来源。雪里蕻放进大缸走普通 `PICKLE` 腌菜配方，产出腌雪里蕻，并计入「翠花，上酸菜！」与「缸缸精通」的腌制判据。
- 相关旧文档：`矿物词典适配.md` 记的是 `c:seeds/*` / `c:crops/*` 标签映射，与本表互补。
