## 3. 落地前必须处理的规则冲突

- `docs/菜肴与食材数值参考表.md` 写明“调料条目也各算一件”，但 `DishFlavors` 里的大盆菜目前是手工填写的食材数，且注释明确把调料排除在 `ingredientCount` 之外。因此现有 8 道菜的实际时长并不是按配方槽数自动算出的。
- 推荐做法：让时长直接从 `BigPotRecipe.ingredients().size() + seasonings().size()` 派生，或由数据生成同步写入，避免以后改配方时再次出现“文档一个数、代码另一个数”。
- 最小改法：把 `DishFlavors` 中这 8 道碗装菜的 `ingredientCount` 全部改成 9，并去掉 `slaughter_feast_bowl`、`sauerkraut_bone_stew_bowl`、`chicken_mushroom_stew_bowl` 的旧 `overrideTicks`。如果暂不调整代码，则不要把本文的 90 秒写进提示或发布说明。
- 现有 `SLOWING_GREASY` 集合保持不变；本次扩容不新增缓慢效果，也不提升任何效果等级。

## 4. 验收项

- JEI 大锅页完整显示 6 个食材槽和 3 个调料槽，标签只占一格并正常轮播可选物品。
- 8 道菜都能按 JEI 投料开工，盖盖加速、容器盛出和盆装方块逻辑不回归。
- 食用碗装成品后，效果种类、等级与上表一致，时长按 90 秒（1800 ticks）计时。
- 1.20.1 与 1.21.1 的配方、JEI 和效果时长一致。
