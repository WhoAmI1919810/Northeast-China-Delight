# 村庄农田、箱子战利品与野生木耳自然生成配置

> 最后核对：2026-10-24，版本 3.2.0+；1.21.1 NeoForge 与 1.20.1 Forge 共用语义。新增野生木耳生成概率；斧头刮树皮不再掉落木耳。桔梗仍只参与野外生成与箱子候选，不进入村庄农田候选。
> 中文名称逐项读取 `assets/northeast_china_delight/lang/zh_cn.json`，运行匹配使用完整物品注册 ID。

## 1. 六项配置

配置位于游戏或服务端目录的 `config/northeast_china_delight-common.toml`。首次启动会自动写入六项默认值；旧配置升级后也会补齐新项。建议退出后编辑并重启，多人游戏以服务端配置为准。

配置说明、默认值与默认名单以两树 `config-templates/northeast_china_delight-common.toml` 的用户确认版本为准，源码 `NortheastChinaConfig.java` 同步维护。当前默认农田名单为 15 项；箱子名单在主树为 69 项、在独立 1.20.1 树为 68 项（1.20.1 没有东北唱片物品）。加载器会按源码校正注释，运行中直接改注释会被还原；需要改说明时应先同步源码，再使用新构建重启。不要拿模板覆盖玩家的自定义配置。

升级旧版时无需删除或重建配置文件：加载器会在原文件中补齐缺少的新项，并保留仍被支持且符合校验规则的旧值。农田和箱子开关默认均为 `true`，允许列表默认包含全部现有候选，所以不修改新配置时维持原生成行为。类型或取值不合法的项会被修正，已不支持的旧键可能被移除；TOML 语法损坏需先修复，不属于正常升级补齐。

两个开关只控制东北乐事自身内容：农田开关决定是否把本模组新增作物替换进村庄农田，不决定农田结构是否生成；箱子开关决定是否允许本模组物品进入箱子战利品，不决定箱子是否生成，也不禁用整张战利品表。关闭后，原版和其他模组的农田作物、箱子物品仍按各自规则生成。

| 配置项 | 默认值 | 作用 |
| --- | --- | --- |
| `worldgen.wild_wood_ear_oak_chance` | `0.05` | 野生木耳在任意群系橡木上的生成概率；`0` 表示不生成 |
| `worldgen.wild_wood_ear_forest_chance` | `0.07` | 野生木耳在黑森林深色橡木、白桦林 / 原始桦木林白桦上的生成概率；`0` 表示不生成 |
| `worldgen.village_farm_crops_enabled` | `true` | 是否启用本模组的村庄农田作物替换 |
| `worldgen.village_farm_allowed_crops` | 下表全部 15 项 | 哪些播种物品对应的作物可以替换进村庄农田 |
| `chest_loot.enabled` | `true` | 是否允许本模组物品在箱子战利品中生成 |
| `chest_loot.allowed_items` | 主树下表全部 69 项（1.20.1 为 68 项） | 哪些本模组物品可以保留在箱子战利品中 |

布尔开关为 `false` 时忽略相应允许列表，直接停止该途径生成本模组候选；布尔开关为 `true` 但列表为 `[]` 时，同样不生成任何本模组候选。农田与箱子彼此独立。

两个野生木耳概率取值为 `0.0 ~ 1.0`，只影响**新生成区块**，已生成区块不会回溯补生成。概率为 `0` 等同于关闭该树种的野生生成；树种与群系限制仍然生效。斧头刮树皮不再掉落木耳，因此调整这两项不会影响任何工具交互收益。

填写大小写正确的完整注册 ID，例如 `northeast_china_delight:soybean`；不要填写中文名、单独的路径、作物方块 ID 或标签。格式正确但没有对应现有候选的 ID 安全无效，不会凭空增加物品。列表是筛选器，不是配方或候选池定义。

## 2. 示例（不是默认完整名单）

以下只允许平原/针叶林的大豆、平原的玉米，以及箱子中的大豆和盐：

```toml
[worldgen]
wild_wood_ear_oak_chance = 0.05
wild_wood_ear_forest_chance = 0.07
village_farm_crops_enabled = true
village_farm_allowed_crops = [
    "northeast_china_delight:soybean",
    "northeast_china_delight:corn_seeds"
]

[chest_loot]
enabled = true
allowed_items = [
    "northeast_china_delight:soybean",
    "northeast_china_delight:salt"
]
```

不要重复添加已有的 `[worldgen]` 节；应在原节中修改或添加所需项，同时保留 `yard_parts_enabled` 等原配置。若只想完全关闭一种生成，将对应的布尔值改为 `false`、概率改为 `0`，无需删除默认名单。

桔梗不在这 15 项农田候选内；它只按 `worldgen/bellflower_scatter` 在指定群系零散生成，因此开关本表不会禁用或启用野生桔梗。

缩小允许列表不会把剩余作物的概率重新归一化，也不会将某作物分配到原先不支持的气候。因此本模组作物占比会相应降低，更多位置留给后续原版/其他模组规则。全部默认候选开启时的各气候比例见 `结构生成说明.md`。

仅影响新生成的村庄农田；不改已有植株，不影响玩家种植/收获、商人交易、合成或野外人参、榛子、榛蘑、桔梗等生成。僵尸村农田沿用原来未替换的规则。

### 3.1 野生木耳生成概率

- 橡木：所有群系均按 `wild_wood_ear_oak_chance` 尝试生成。
- 深色橡木：只在黑森林按 `wild_wood_ear_forest_chance` 尝试生成。
- 白桦：只在白桦林 / 原始白桦林按 `wild_wood_ear_forest_chance` 尝试生成。
- 其他树种、去皮的木头、没有树叶的裸露原木（包括村庄木屋框架）不会生成。

野生木耳仍要求原木附近存在树叶，并按世界生成阶段执行；概率只在掷骰时读取，区块生成后修改配置不会改变该区块已有结果。

## 5. 实现与验证

- 配置：`NortheastChinaConfig`，两版均使用可为空的字符串列表，并在读取时按完整 ID 匹配。
- 野生木耳：`WoodEarRules#wildChance` 读取 `worldgen.wild_wood_ear_*_chance`；`WildWoodEarFeature` 负责树冠识别与放置。原有斧头刮皮掉落监听已移除，JEI 也不再说明刮皮获取。
- 农田：`worldgen/VillageFarmCropRuleTest`；`ModWorldGen.RULE_TESTS` 注册 `northeast_china_delight:village_farm_crop`。六份 JSON 只改变本模组规则的输入谓词类型并增加 `crop_item` 字段，原概率及原版规则保留。
- 箱子：`loot/ChestLootConfigModifier`；四种注入器在总开关关闭时立即返回，且在加入单个物品前检查允许列表。末尾全局过滤根据真实表类型处理本模组物品；原来的钓鱼和实体修改器没有改动。
- 测试：`GenerationConfigGameTests` 新增 14 项，覆盖默认概率、全部气候、空列表、单项筛选、其他模组保留、各注入池、三个小院箱子、非箱子掉落和两组开关独立性。
- 木耳测试：`WoodEarGameTests#wildWoodEarUsesConfiguredChance` 覆盖配置读取、橡木概率生效、概率为 0 时不生成、非目标树种与去皮原木仍为 0。
- 1.21.1 隔离离线测试 63 项中 58 项通过；本轮新增 14 项全部通过，原有 5 项失败未修改。日志：`E:\codex\tmp\generation-config-gametest-r2-20261013.log`；世界、配置和日志均在 E 盘，不复用开发客户端目录。
- 1.20.1 已离线构建验证；完整 JEI 运行依赖仍未缓存，因此本轮不声明 Forge 运行测试通过。
