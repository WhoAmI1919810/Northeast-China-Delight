### 2. 历史（.git）体积问题

- `.git` 约 **411 MB**：其中约 391 MB 是不可达的松散对象（历次 `git add` 又撤下的大文件残留），
  真正可达历史 ≈ 20 MB。
- 可达历史里同样混着 `lib/`+`libs/` jar、`.tmp` dll、`now.png` 旧版、`eclipse/` 目录等。
- 决定：用 git-filter-repo 重写历史，把这些路径从所有提交里剔除，再 `git gc` 压缩。

- `src/main/templates-forge/`、`src/main/templates-legacy/`（1.20.1 Forge / 1.20.4 元数据模板）

### 4. 与源码无关的痕迹

- README / `logs/README.md` / `tools/*` 脚本里有多处 `E:\codex`、`H:\miniconda3`、
  「Codex 工作目录」等本机 / AI 工作流痕迹。
