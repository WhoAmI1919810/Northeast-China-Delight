## 6. 冻梨 / 黑土地 / 动物油块的作用

### 6.1 冻梨

- 新食材：**梨**（树或村庄果树）+ **冻梨**（梨在雪地/冰上、或大缸加雪盖布冷冻 1 个单位时间得到）；
- 食物设计：饥饿值低但给**爽口 + 短时抗寒/降温**；可作为"解腻"道具（吃油腻菜后吃一个）；
- 美术：梨、冻梨（深褐带霜）、梨树/树叶（可选）。

### 6.2 黑土地（世界生成 —— 目前完全没有）

- 新方块：**黑土地**（东北黑土），生成在平原/森林/针叶林的表层（用 `placed_feature` 铺一片）；
- 作用：上面种的作物**生长更快**（随机刻加成）或**掉落 +1**；铲子可挖成普通泥土；
- 需要新增：`data/dongbei_delight/worldgen/configured_feature` + `placed_feature` + 生物群系修饰器，
  以及黑土地的 3 张贴图（顶/侧/底）。

### 6.3 动物油块的作用（现在只是"更白的蜂蜜块"）

四选一或组合：

1. **燃料**：一格动物油块可冶炼 20 个物品（对标煤炭块）；
2. **蜡**：右键给铜块打蜡（防止氧化）—— 和"油"的语义最贴；
3. **蜂蜜块特性保留**：减速 + 可弹跳 + 可粘活塞；
4. **料理用途**：2 块动物油块 + 玻璃瓶 = 4 瓶动物油（反向拆解），或做"油纸"包装食物（延长保质期概念）。

### 6.4 油脂的消耗规则（已实现）

* 瓶装调料统一 **250 mB / 瓶，一次 50 mB**（耐久条就是剩余量），植物油和动物油也一样；
* **油炸菜**（`#dongbei_delight:deep_fried_dishes`：老派/新派/橙汁锅包肉、溜肉段、拔丝地瓜、雪绵豆沙）
  用油时**一次用光一整瓶**，只返还空玻璃瓶 —— 一锅油下去了，剩下的油不能接着炒菜；
* 煎、炒、炖等做法照常按 50 mB 扣。两个集合都在数据包标签里：
  `tags/item/deep_fry_oils.json`（哪些油会炸完）、`tags/item/deep_fried_dishes.json`（哪些菜算油炸），
  以后加菜加调料只改标签，不动代码。

### 6.5 燃料（已实现）

三种物品可以当燃料烧，数值写在 **NeoForge 的燃料数据表**里：
`data/neoforge/data_maps/item/furnace_fuels.json`

| 物品 | 燃烧时长 | 备注 |
| --- | --- | --- |
| 玉米茎秆 | 200 刻（10 秒） | = 树苗/木棍的档次 |
| 动物油（瓶） | 800 刻（40 秒） | 一瓶 = 半块煤 |
| 动物油块 | 3200 刻（160 秒） | = 4 瓶动物油，换算一致 |

走的是 `ItemStack#getBurnTime`，所以**熔炉 / 烟熏炉 / 高炉 / 机械动力烈焰燃烧器**全都认；
想再给别的物品加燃料，往这张表里加一行即可（数值单位是刻）。

### 8.1 大缸回归清单（引擎接线后跑一遍）

每条都验"能不能成 + 缸里看起来对不对 + 取出来是什么"三件事：

| # | 配方 | 关键点 |
| --- | --- | --- |
| 1 | 泡菜（1/2/3 层水） | 每层 2 份菜 + 1 份盐，压石头；腌完水位不变、变成等量酸引水、菜还是菜，取出来是腌菜 |
| 2 | 辣白菜（1/2/3 层水） | 白菜 + 盐 + 辣椒酱 + 1~2 份鱼露/虾酱；白菜出来是辣白菜，混进去的黄瓜出来还是酸黄瓜 |
| 3 | 咸腊肉 | 1~6 块肉配同样多的盐，压石头；腌完肉是白的，取出来是咸腊肉 |
| 4 | 咸鱼 | 任意生鱼配同样多的盐；6 条鱼 + 3 份盐会转成鱼露 |
| 5 | 大酱 | 3 层水 + 3 酱块 + 3 盐 + 羊毛地毯；缸里剩 3 块酱渣，用碗能装 10 碗 |
| 6 | 酱油 | 大酱的料再加 1 份小麦；产物是 10 瓶酱油 |
| 7 | 醋 | 大酱 / 酱油取空液体后，3 酱渣 + 3 谷物 + 至少 1 层水 + 粗布毯 |
| 8 | 白醋 | 泡菜剩下的酸引水（≥750 mB）+ 3 谷物 + 粗布毯；只喝掉 750 mB，剩下的还能装瓶 |
| 9 | 鱼露 / 虾酱 | 6 份 + 3 份盐，压石头；全化掉，只出 1 瓶 |
| 10 | 豆芽 | 1 层水 + 1~2 黄豆 + 粗布毯；一份黄豆出一份豆芽 |
| 11 | 酸玉米粒 | 每层水 2 份玉米粒（2~3 层水不再卡住）+ 粗布毯 |
| 12 | 格瓦斯 | 3 层水 + 6 个面包 + 粗布毯；出 6 瓶 |
| 13 | 倒酸引水 | 空缸能倒、腌好的泡菜缸能攒；**有清水的缸和正在腌的缸一律不许倒** |
| 14 | 加水 | 空缸 / 只剩酱渣的酱缸能加；有酸引水的缸不许加；做过一次之后不再收水 |
| 15 | 流体管道 | 大酱 / 酱油 / 醋 / 白醋 / 鱼露 / 虾酱 / 酸引水都能被抽走，抽空后酱渣还在缸里 |
| 16 | JEI | 每条配方的投料格、份数、封口物、发酵时长、液体都对得上；辣白菜那一页有 4 个格子（白菜 / 盐 / 辣椒酱 / 鱼露·虾酱） |
