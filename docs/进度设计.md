## 判据从哪来

绝大多数判据是原版触发器，整条写在 `advancement/*.json` 里；只改文案 / 图标 / 图标物品不用碰代码：

| 进度 | 判据 | 触发器 |
| --- | --- | --- |
| 东北乐事 | `smelted` / `vat` | `recipe_crafted` / `inventory_changed` |
| 快乐老家 | `yard` | `location`（结构 `northeast_china_delight:northeast_yard`） |
| 有臼了！ | `placed` | `placed_block`（木臼） |
| 家乡之声 | `play` | `item_used_on_block` + 唱片机 + `match_tool`（仅 1.21.1） |

下面这几条的触发时机在原版没有对应触发器（「敲中一下」「末影人记仇」「走进第 n 种院子」），判据写成
`minecraft:impossible`，由玩法代码调 `ModAdvancements.award(...)` 直接发放：

| 进度 | 判据 | 发放位置 |
| --- | --- | --- |
| 开舂 | `pound` | `block/WoodenMortarBlock` —— 木槌敲中一下；判据只认「用的是什么工具」，不认配方，以后加新舂捣配方不用回来改 |
| 大锤小用 | `pound` | 同上（手里是 1.21+ 重锤时改发这条；仅 1.21.1） |
| 你瞅啥？ | `stare` | `event/ModGameplayEvents` —— 戴盆持槌把末影人惹毛的那一刻 |
| 挨户串门 | `garden` / `compound` / `livestock` | `event/ModGameplayEvents` —— 每 20 tick 查一次玩家踩在哪个院子里 |

「挨户串门」一条判据对一个院子模板：`northeast_china_delight:northeast_yard_garden` → `garden`
（去掉命名空间和 `northeast_yard_` 前缀，规则在 `ModAdvancements.yardCriterion`）。三种院子共用一个结构 id、
共用 `minecraft:location` 触发器，数据包分不出进的是哪一种，所以只能写代码。往
`NortheastCourtyardStructure.DEFAULT_TEMPLATES` 加新院子模板时，要在 `visit_all_yards.json` 的 `criteria` 里
补一条同名判据，并在 `requirements` 里按「一条判据一组」加上，否则进了那种院子不算数。
