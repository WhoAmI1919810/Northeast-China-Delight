### 几条硬规矩（改模板时别破坏）

1. **地面是草方块**：`y=1` 是院子地面（草），`y=0` 只是垫土。
2. **工作面摆在地上**：房子楼板、院墙、栅栏、工作台、大缸、烤架、Create 石磨、
   箱子木桶全在 `y=2` 及以上，不和草地同层。
3. **不用干草捆**：茅草顶、草垛用 `yellow_wool`、牲口垫料用 `brown_wool`，
   灶棚柱子用 `spruce_fence`——不用干草捆（hay_block 一拆就是 9 个小麦，破坏生存平衡）。
4. **正房内部是三开间**：中间灶房（炉灶 + 烟熏炉 + 锅 + 案板 + 水缸 + 木桶），
   东西两屋（火炕 + 被褥床 + 柜子 + 花盆 + 吊灯），隔断墙留门洞，房梁在墙顶那一层
   （`tools/structure_gen/parts.py` 的 `interior_three_bay`）。
5. **门口不能有遮挡**：正房门前 3 格宽 × 4 格深必须是空地，菜园围栏/柴垛/灶棚
   都不许压上去；`validate_structures.py` 会逐扇门自检并报错。
6. **井口与地面平齐**：石圈和水都在地面那一层，井架再往上搭。
7. **院子对齐地面**：生成时原点压到地表以下（`surface - GROUND_LAYER_IN_TEMPLATE - 1`），
   模板里的垫土全埋进地形，草地和自然地面齐平。
8. **梯子**：苞米楼子南面搭了一架梯子（从地面直通楼板），粮仓进得去。

院内细节零件（`tools/structure_gen/parts.py`）：房基散水、门斗、山墙烟囱、窗台窗板、
夹杖子围墙、门楼、影壁、菜窖、猪圈、鸡架、狗窝、酱缸阵、粮囤、柴垛、水井辘轳、
石磨石碾、晒场、旱厕、晾衣绳。

六种院子都是「坐北朝南」：正房在北、院门开在南墙。

## 2. 生成规则

1. 结构只在**寒冷覆雪**的生物群系里刷（默认：针叶林系 + 雪原系，见下面第 3 节的生物群系标签）。
2. 刷出来的不是一个院子，而是一片**小院群落**：
   - 每个院子在**东、西、南、北四个方向各掷一次**；
   - 每个方向随机取 20~50 格的距离，有 **30%** 概率再长一个院子；
     （`step_measure` 决定这个距离怎么量：默认 `gap` = 两个院子之间的**空隙**，
     因为院子放大到 30~48 格之后，按原点距离 20~50 会互相压住；想要旧行为就改成 `center`。）
   - 新院子重复同样的过程，直到掷不中、位置不合法、不是寒冷群系，或到达 **20 户**上限。
3. 「位置合法」= 地面不是水（水面高度 ≠ 海底高度）、四角高差不超过 `max_slope`、
   和已有院子之间留够 `min_gap` 格缝隙、在地图高度范围内。

## 3. 想改参数，只动数据包（不用改代码）

### 生物群系

`data/northeast_china_delight/tags/worldgen/biome/has_dongbei_yard.json`

```json
{ "values": ["#minecraft:is_taiga", "minecraft:snowy_plains", ...] }
```

想让它出现在别的群系，就往数组里加；想只在更冷的地方，就删几行。

### 概率 / 游走

`data/northeast_china_delight/worldgen/structure/dongbei_yard.json`

| 字段 | 默认 | 作用 |
| --- | --- | --- |
| `templates` | 6 种院子 | 抽签池；加一行就多一种院子 |
| `origin_chance` | 0.85 | 总概率闸门，越小越稀有 |
| `walk_chance` | 0.80 | **第一户**继续长新院的概率；之后每户 -15%，降到 20% 封底（80/65/50/35/20/20…） |
| `step_min` / `step_max` | 20 / 50 | 游走距离范围（格，默认量的是两院之间的空隙） |
| `step_measure` | gap | `gap`=量空隙，`center`=量原点距离 |
| `lateral_jitter` | 6 | 游走时的横向随机偏移，避免村子排成一条直线 |
| `max_houses` | 20 | 一个群落最多几户 |
| `min_gap` | 1 | 两个院子之间至少留几格缝 |
| `max_slope` | 6 | 地形高差超过这个数就不生成 |
| `allow_flip` | true | 是否允许院子朝南/朝北两种朝向 |
| `black_soil_chance` | 0.35 | 这一户周围要不要长黑土地 |
| `black_soil_radius` | 18 | 黑土地散布半径（格） |
| `clear_above` | 30 | 院子正上方要留多少格空气（不够就清掉树冠） |
| `clear_radius` | 20 | 院子外扩多少格清树/灌木/花草等地物 |
| `gate_check_depth` | 12 | 门口前方检查多深（0 = 不检查朝向） |

另外几个数是 Java 里的常量（`DongbeiCourtyardStructure`），改一个数就生效：
`
LATERAL_JITTER`（游走横向偏移，6）、`GATE_CHECK_WIDTH`（门口检查宽度，18）、
`MAX_GATE_SLOPE`（门口高差容忍，4）、`BLACK_SOIL_DENSITY`（黑土地密度，0.12）、
`GROUND_LAYER_IN_TEMPLATE`（模板里草地是第几层，3）。

**朝向检查**：每个院子在「朝南 / 朝北」两个朝向里挑一个门口前方能走人的——
门口前方 `gate_check_depth × GATE_CHECK_WIDTH` 的范围内不能是水面，地形高差不能超过
`MAX_GATE_SLOPE`；两个朝向都不合格就放弃这一户（游走到此为止）。

**净空与清场**：结构放在 `top_layer_modification` 阶段（比种树晚），
生成时先给每个院子加一个"清场件"，把院子上方 30 格和半径 20 格内的树、灌木、
花草清掉，然后再放院子本体——所以院子自带的那棵大树不会被自己清掉。

### 刷新密度

`data/northeast_china_delight/worldgen/structure_set/dongbei_yards.json`

```json
"placement": { "type": "minecraft:random_spread", "spacing": 40, "separation": 16, "salt": 20260930 }
```

`spacing`（每多少格试一次）和 `separation`（同格内最小间隔）越小，东北小院越密。

## 4. 黑土地

- 每个院子有 `black_soil_chance` 概率在周围 `black_soil_radius` 格内撒沃土；
- 逐格按 `black_soil_density` 概率把表层的**草方块 / 泥土 / 砂土 / 灰化土 / 菌丝 / 雪**换成
  农夫乐事的 **沃土（`farmersdelight:rich_soil`）**；
- 雪盖会先扫掉，不然看不见黑土；
- 没装农夫乐事时整段自动跳过，不会报错。

实现：`src/main/java/com/gunmu/northeast_china_delight/worldgen/BlackSoilPiece.java`

## 5. 怎么加一种新院子

1. 在 `tools/structure_gen/designs.py` 里照着现有函数写一个（或者用结构方块手搓导出）；
2. 跑 `python tools/structure_gen/build_structures.py` 生成 NBT；
3. 跑 `python tools/structure_gen/validate_structures.py` 自检（方块名、属性、门成对、坡向）；
4. 跑 `python tools/structure_gen/render_structure.py` 出三视图看形体；
5. 把新 NBT 名加进 `dongbei_yard.json` 的 `templates` 数组。

## 6. 配套改动

### 副食店（村庄建筑）

- 5 个群系各一间（12×7×7 的平顶小店）：`data/northeast_china_delight/structure/village/relish_<群系>.nbt`
  - `plains` / `savanna` —— 直接用你做的两张 NBT（补上村庄接口）
  - `desert` / `snowy` / `taiga` —— 按平原版换材质生成（沙漠=砂岩系、雪原/针叶林=云杉+圆石/苔石）
- 店里固定有一口 **大缸**（副食商的工作方块）和箱装/袋装货架；
- 门口带 `minecraft:building_entrance` jigsaw（接村庄街道）、屋里带 `minecraft:bottom`
  jigsaw（刷村民），所以村里的村民会去认领那口缸、转职成副食商；
- 已挂进原版村庄房屋池：`data/minecraft/worldgen/template_pool/village/<群系>/houses.json`
  （连僵尸村一起，权重 2）。想做"更多副食店"就把 `tools/structure_gen/build_village_pools.py`
  里的 `WEIGHT` 调大重跑。

### 寒冷群系的专属交易

辣白菜、酸菜、腌青萝卜、大酱这四样**只有寒冷群系村庄的副食商卖**
（村民类型是 `minecraft:snow` 或 `minecraft:taiga` 时才会出现这些报价，
其他群系的副食商返回空报价，游戏自动跳过）。实现见
`SideDishMerchantTrades#coldOnly`。

- **黑土地**：见上。
- **动物油块**：在工作盆里用动力搅拌器加热，1 块 → 1000 mB 动物油
  （`data/northeast_china_delight/recipe/mixing/animal_oil_block.json`）。
- **暖身（状态效果）**：汤类料理吃完额外获得，在寒冷覆雪生物群系里
  移动速度 +5% × 等级，且不会陷进细雪。
  - 生效范围按生物群系基础温度判断，阈值是 `DishEffectEvents.COLD_TEMPERATURE`（默认 0.15）；
  - 哪些菜算汤：`DishFlavors.SOUP_PATHS` 名单；
  - 「不陷细雪」由 `mixin/PowderSnowBlockMixin` 打在原版细雪方块上；
  - 图标暂时复用现有效果图标（`textures/mob_effect/warmth.png`），以后换新图直接替换同名文件即可。
