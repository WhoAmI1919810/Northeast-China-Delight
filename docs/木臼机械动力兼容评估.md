# 木臼「舂捣」产物与机械动力制作渠道

> 日期：2026-11-07  
> 本文回答的是：木臼舂捣产出的物品，能否通过机械动力现有配方获得；不讨论木臼本身能否被自动化。

## 结论

- **已补 Create 渠道**：豆沙、花生糕。
- **原本已有 Create 渠道**：花生酱；玉米/大豆榨出的植物油，其产物本身另有熟花生压榨路线。
- **仍无 Create 渠道**：打糕。
- **按设计不需要 Create 渠道**：湿粉团。

## 逐配方核对

| 木臼配方 | 木臼产物 | Create 现成渠道 | 说明 |
|---|---|---:|---|
| `pounding/rice_cake` | 打糕 ×4 | 无 | 工作盆冲压没有“冲压次数”字段；现有数据格式无法要求四次冲压 |
| `pounding/red_bean_paste` | 豆沙 ×2 | 有 | 工作盆动力搅拌：1 红豆 + 1 糖 → 3 豆沙 |
| `pounding/peanut_cake` | 花生糕 ×2 | 有 | 工作盆动力冲压：2 熟花生米 + 250 mB 蜂蜜 → 4 花生糕 |
| `pounding/wet_starch_dough` | 湿粉团 ×2 | 不需要 | 按当前设计不补机械动力配方 |
| `pounding/peanut_butter` | 花生酱 ×1 + 50 mB | 有 | `create:mixing`：熟花生米 → 250 mB 花生酱；再用 250 mB 灌瓶 |
| `pounding/corn_oil` | 植物油 ×1 + 50 mB | 产物有，原料路线不同 | Create 可用熟花生米压榨植物油，但没有玉米种子榨油配方 |
| `pounding/soybean_oil` | 植物油 ×1 + 50 mB | 产物有，原料路线不同 | 同上，没有大豆榨油配方 |

## 本次新增配方

### 豆沙

文件：`data/northeast_china_delight/recipe/mixing/red_bean_paste.json`

- 类型：`create:mixing`
- 输入：`c:crops/red_bean` ×1、`c:sugar` ×1
- 输出：`northeast_china_delight:red_bean_paste` ×3

### 花生糕

文件：`data/northeast_china_delight/recipe/compacting/peanut_cake.json`

- 类型：`create:compacting`
- 输入：`northeast_china_delight:roasted_peanuts` ×2、`create:honey` 250 mB
- 输出：`northeast_china_delight:peanut_cake` ×4

## 打糕的四次冲压检查

Create 的 `create:compacting`（工作盆 + 机械压机）是单次转化配方；`ProcessingRecipeParams` 只有处理时长，没有“需要几次冲压”字段。因此下面这条要求不能直接用数据包实现：

- 盆装米饭放进工作盆
- 动力冲压 4 次
- 得到 4 份打糕并返还大盆

可行的替代路线：

1. **单次冲压 + 4 倍处理时长**：最容易，但只是耗时变长，不是真正的四次冲压，未采用。
2. **流水线组装 `loops: 4`**：确实会经历四次压机步骤，但机器是传送带/ Depot，不是工作盆；且产物池只选一个结果，不能稳定同时返还大盆，未采用。
3. **增加隐藏中间物品，连续四次工作盆冲压**：第一至第三次分别产出下一阶段中间物，第四次产出 4 份打糕 + 大盆。能完全符合描述，但需要新增 3 个中间物品，并会污染 Create / JEI 的配方展示，属于侵入式方案，暂未实现。

## 附注：木臼自身自动化

以上结论仅针对产物渠道。木臼本身仍没有 Create 的物品栏接口，装料依赖玩家右键，舂捣依赖蓄力左键事件，取货也依赖玩家空手或持瓶操作，所以不能用机械手、部署器或流水线直接完成木臼加工。这是木臼交互层的限制，不等于产物没有 Create 配方。
