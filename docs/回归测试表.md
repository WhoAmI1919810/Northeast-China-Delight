## 1.1 大缸（Vat）

前置：创造模式，`/give @p northeast_china_delight:vat`；配方清单见 `data/northeast_china_delight/recipe/vat/`（15 个）。

- [ ] **V-01 碰撞箱**：空缸可以直接踩上去、贴边行走（与堆肥桶一致）；一旦开始制作，碰撞箱变成整块。
- [ ] **V-02 空手取出成品**：豆芽 / 酸玉米粒 / 酸菜 / 酱渣 / 泡菜做好后，**空手右键直接取出**，不再只提示「可以取货了」。
- [ ] **V-03 先揭毯再取**：盖着粗布毯完成时，第一次右键是揭毯，第二次才取货。
- [ ] **V-04 容器取货**：格瓦斯必须用瓶子取（成品是液体，不是瓶装格瓦斯）；JEI 页要同时画出液体和瓶子。
- [ ] **V-20 调料整份**：20 mB 瓶装调料右键大缸 `perDose` 配方应被拒绝，瓶子保持 20 mB；满瓶 / 200 mB 瓶只扣 50 mB，最后一份返空玻璃瓶。
- [ ] **V-05 进度文案带动词**：右键查进度时显示配方自己的动词（发酵 / 酿造 / 发芽 / 腌制…）；自定义字面量与翻译键都能生效；非法动词被拒绝。
- [ ] **V-06 用量与产出**：豆芽 1000 mB 水即可；白醋 / 米醋统一成「一缸」的量；普通泡菜产出 3 桶酸水；JEI 上的数量与实做一致（不允许「不论注多少水，JEI 都写 2500 mB」）。
- [ ] **V-07 酱油渣连续制醋**：取完酱油后缸里留着酱渣，直接加水 + 谷物 + 蒙毯就能开始下一轮，右键不会先把酱渣掏出去。
- [ ] **V-08 成品液体没取尽时拒绝接新配方**（留缸续做的边界）。
- [ ] **V-09 禁用配方**：数据包里写 `disabled=true` → 投料退回、可清空、不开始计时、已完成的液体保留。
- [ ] **V-10 数据包覆盖**：同路径覆盖 / 新增 / 按 id 优先级生效（见 `docs/大缸配方数据包用法.md`）。
- [ ] **V-11 JEI 取出容器**：每个成品的取出方式（空手 / 碗 / 瓶 / 桶）都要在 JEI 页上体现，且只写一句提示。
- [ ] **V-12 配方自检**：GameTest `vatRecipesPassSelfCheck` 通过。
- [ ] **V-13 冻豆腐**：寒冷群系、空缸、豆腐 1~6 + 顶层压雪块，30 秒后取出冻豆腐；普通豆腐不能直接当成品用于杀猪菜/酸菜海鲜锅，必须用冻豆腐。
- [ ] **V-14 发酵中水量上限**：豆芽只加 1 层水，再倒第二桶应被拒绝；冻梨 / 冻豆腐只压雪块、不加水，倒水应被拒绝。拒绝后进度继续走，不能停在失配状态。
- [ ] **V-15 进度失配恢复**：人为把一缸 `PROGRESS` 写成大于 0、且水量超过当前配方上限；空手右键后进度回到 0、旧配方绑定解除，可重新投料 / 封口开工。
- [ ] **V-16 泡菜 JEI 拆页**：JEI 搜酸菜应看到「蔬菜 + 盐」；搜辣白菜只应出现大白菜，并看到「大白菜 + 盐 + 辣椒酱 + 鱼露/虾酱」。两页不能是同一张图，且按页面材料能实际开工。
- [ ] **V-17 辣白菜同族边界**：辣味配方只接受大白菜；黄瓜 / 胡萝卜 / 青萝卜手持辣椒酱时不能开工。通过数据包扩 `spicy_pickle_ingredients` 标签并补 `mapped` 映射后，新同族原料应产出对应成品，JEI 按产物拆页。
- [ ] **V-18 辣白菜无水干腌与批量**：空缸直接放入大白菜 1–6 棵 + 盐 + 辣椒酱（鱼露/虾酱可选），压上压缸石即可开工；盐按每 2 棵 1 份跟随主料（4 棵 2 份、6 棵 3 份，1 棵仍 1 份）。不加水、不产酸引水，完成后空手右键逐棵取出辣白菜；4 棵与 6 棵批次都要实际跑通。JEI 页不显示水位、酸引水或取液容器；普通泡菜仍按水位产出酸引水。
- [ ] **V-19 腌雪里蕻走普通泡菜**：空缸加 1–3 层水，放雪里蕻（每层 1–2 棵）和对应盐，压上压缸石；完成后雪里蕻被保留为腌雪里蕻，空手逐棵取出，酸引水按普通泡菜规则产出。JEI 搜腌雪里蕻应能看到同一条 `vat/pickle` 页面，不得另开重复配方。
