# 配方与标签修复记录（2.8.5，2026-10-09）

这一轮修的是一批「配方看起来在、实际匹配不到东西 / 匹配得太宽」的问题，
外加四条针对大缸的调整（盐量、时长、寒冷惩罚、JEI 海水桶信息页）。

## 一、根因：1.20.x 标签改名只改了引用，没改定义

`gradle/legacy-data-port.groovy` 的 `legacyTagPathRenames` 会把 1.21 的 `c:foods/raw_fish`
改成 1.20.x 的 `forge:raw_fishes`（跟着农夫乐事的名字走），但只改**配方里的引用**，
**标签定义文件本身还停在 `data/forge/tags/items/foods/raw_fish.json`**。结果：

| 现象 | 原因 |
| --- | --- |
| 红烧带鱼 / 干炸带鱼收别家的鱼、不收本模组带鱼 | 定义挂在 `forge:foods/raw_fish`，配方查的是 `forge:raw_fishes`（农夫乐事只往里放了鳕鱼 / 鲑鱼 / 热带鱼） |
| 大缸咸鱼、鱼露的原料格是空的（JEI 里那条配方没有可放的物品） | `VatRecipes.RAW_FISH` 写死 `c:foods/raw_fish`，1.20.x 的 Forge 根本没有 `c:` 命名空间 |
| 大缸冻梨的原料格是空的 | 果园乐事 1.20.1 用的是 `forge:fruits/pear`，而 `ModTags` 查的是 `forge:foods/fruits/pear`（改名表漏了这条） |

修法：

- 改名表补 `foods/fruits/pear → fruits/pear`（`ModTags.legacyPath()` 与 groovy 两边同步）；
- 转换脚本除了改引用，**连标签定义文件的路径一起改**（`foods/raw_fish.json → raw_fishes.json`）；
- `VatRecipes` 不再自己拼 `c:foods/raw_fish`，改用 `ModTags.FOODS_RAW_FISH`（按版本取标签）。

顺带修掉 1.21.1 的一条空配方：三鲜饺子的面团用的是 `c:foods/dough/wheat`，
1.21.1 上农夫乐事只定义了 `c:foods/dough`、机械动力只定义了 `c:doughs/wheat`，没人定义 `c:foods/dough/wheat`。
现在本模组自己定义了它（`data/c/tags/item/foods/dough/wheat.json` = `farmersdelight:wheat_dough` + `create:dough`），
1.20.x 转换后落成 `forge:dough/wheat`，和两家的同名标签合并。

## 二、大缸原料收窄

| 要求 | 处理 |
| --- | --- |
| 酸菜 / 辣白菜不能用卷心菜（`c:crops/cabbage` 含农夫乐事的卷心菜和卷心菜叶） | `isPickleIngredient` 去掉 `CROPS_CABBAGE`，只认 `c:crops/napa_cabbage`（大白菜）+ 本模组自己的菜 + 黄瓜 / 胡萝卜 / 萝卜通用标签。别家的大白菜往 `c:crops/napa_cabbage` 里塞即可 |
| 「发酵酸菜的产物里有卷心菜」 | `pickleConverter` 不再"认不出来就原样返回"：一律换成本模组的成品（黄瓜→酸黄瓜、萝卜→酸萝卜、其余→酸菜），缸里不会留别家的原物 |
| 培根不能用来腌肉 | `isMeatInput` 在 `c:foods/raw_pork` 之外多排一道：id 是 `bacon` 或以 `_bacon` 结尾的一律不收（农夫乐事把 bacon 塞进了 raw_pork） |
| 大缸产物只能是本模组内容 | 全表核对：所有 `KEEP` / `CONVERT` / `product` 的产物都是本模组物品；唯一的漏洞就是上面那条"原样返回"，已修 |

## 三、箱装 / 袋装只收本模组原料

25 个 `*_crate` / `*_sack` 配方里的 `c:crops/*`、`c:seeds/*`、`c:foods/pickles|kimchi|sauerkraut`、`c:mushrooms`
全部换成 `northeast_china_delight:<物品>`（例：原版蘑菇不能再合成袋装榛蘑）。解包配方本来就是直连物品，不用动。

## 四、大缸参数调整

- **盐量**：咸腊肉 / 咸鱼从"肉与盐一比一（满缸 6+6）"改成"盐 = 肉数的一半，向上取整，最多 3 份"
  （新增 `VatRecipe.BoundsRule.halfOf`）。满缸 6 块只要 3 份盐，只腌 1 块也只要 1 份；JEI 里显示的也是 3 份。
- **时长**：整张表统一减半 —— 泡菜 / 辣白菜 1200→600 秒/层、腊肉 2400→1200、咸鱼 2400→1200、
  大酱 / 酱油 6000→3000、醋 4800→2400、白醋 3600→1800、鱼露 / 虾酱 4800→2400、
  豆芽 600→300、酸玉米粒 1200→600、格瓦斯 1200→600、冻梨 600→300。
- **寒冷惩罚削弱**：冷带倍率把"多出来的部分"减半 —— 原来 ×2.0 的改 ×1.5（泡菜类、豆芽），
  原来 ×1.5 的改 ×1.25（酱酵类、格瓦斯）。温带 / 暖带 / 热带不变。

## 五、JEI 补充海水桶信息页

新增 `jei.northeast_china_delight.info.sea_water_bucket`（中英双语）：怎么在海洋里取海水、
只能倒回干净海水里（水下对着水面或海底右键，倒掉换回空桶，不能放到岸上）、
厨锅煮 / 烟熏炉熏出盐。

## 六、验证

- `:1.21.1:build`、`:1.20.1:build` 均成功（2.8.5）。
- 对 1.20.1 / 1.21.1 两个真实整合包目录做了标签审计：本模组配方里引用的 `c:` / `forge:` 标签**全部有定义**
  （1.20.1 的空配方就是靠这一步定位的）。
- 1.20.1 产物里已确认存在 `data/forge/tags/items/raw_fishes.json`（含带鱼、虾、海参、生蚝）与
  `data/forge/tags/items/dough/wheat.json`；箱装袋装配方已全部改成直连物品。
