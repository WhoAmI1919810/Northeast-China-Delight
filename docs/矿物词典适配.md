# 矿物词典适配说明

## 背景

1.21.1 已经没有 Forge 时代的「矿物词典（Ore Dictionary）」注册表，NeoForge 沿用的等价机制是 **`c:` 命名空间的通用标签**。模组把自己的物品写进 `data/c/tags/item/...`，配方里用 `{"tag": "c:..."}` 或 `Ingredient.of(TagKey)` 引用，别家模组的同种物品只要在同一个标签下，就能直接被配方认出来。

检索参考：[mcmod.cn 矿物词典检索](https://www.mcmod.cn/oredict.html?mod=0&key=pepper)（老 oreDict 名，如 `cropPepper`、`cropSoybean`，换算到 `c:` 标签就是 `c:crops/...`）。

## 消耗规则（用户要求）

- **别家模组的调料**：没有 mB 计量概念的，**一次用一整份**。
- **本模组的瓶装调料**（`SeasoningBottleItem`）：一次仍然只扣 50 mB，一瓶用 5 次。
- 大缸、烤架、厨锅、工作台四类配方都遵循上面这两条。

### 不装这些模组时会怎样

- 标签里引用的别家物品在游戏里**只是不存在**，配方照常工作，只是少了一个可选原料；
- 本模组的物品依然全部可用，没有任何配方依赖别家模组存在。

## 各配方适配情况

### 大缸（`VatRecipes`）

| 大缸配方 | 原料匹配 | 适配标签 | 备注 |
|---|---|---|---|
| 泡菜 | 蔬菜槽 | `c:crops/napa_cabbage`、`c:crops/cucumber`、`c:crops/carrot`、`c:crops/radish`（+ 本模组精确映射兜底） | 别家的白菜/黄瓜/胡萝卜/萝卜也能腌，腌不出对应产物的退化成酸菜 |
| 辣白菜 | 蔬菜槽、辣椒酱槽、调味槽 | 蔬菜槽同泡菜；辣椒酱 `c:foods/seasonings/chili_sauce`；鱼露/虾酱 `c:foods/seasonings/fish_sauce`+`c:foods/seasonings/shrimp_paste` | 别家的辣椒酱/鱼露可替代 |
| 咸腊肉 | 肉槽 | `c:foods/raw_pork` | 别家的生猪排可腌 |
| 咸鱼 | 鱼槽 | `c:foods/raw_fish`（排除鱼片） | 大虾、生蚝、海参、带鱼都算，别家的整条生鱼也算 |
| 大酱 | 酱块槽 | 本模组 `soy_paste_chunk` 专属 | 酱块只有本模组有，无法替代 |
| 酱油 | 酱块槽 + 小麦 | 酱块同上；小麦 `c:crops/wheat` | 别家的小麦也能酿酱油 |
| 醋 | 酱渣槽 + 谷物 | 酱渣本模组专属；谷物 `c:seeds/corn` 或 `c:crops/buckwheat` | 别家的玉米粒/荞麦可替代 |
| 白醋 | 酸引水 + 谷物 | 同上 | 酸引水是本模组副产物，别家谷物可用 |
| 鱼露 | 生鱼槽 | `c:foods/raw_fish` | 3 条整鱼（虾 / 生蚝 / 海参不算） |
| 虾酱 | 虾槽 | `c:foods/shrimp` | 别家的虾也能熬虾酱 |
| 豆芽 | 黄豆槽 | `c:crops/soybean` | 别家的大豆可发豆芽 |
| 酸玉米粒 | 玉米粒槽 | `c:seeds/corn` | 别家的玉米粒可发酵 |
| 格瓦斯 | 面包槽 | `c:foods/bread` | 别家的面包可酿格瓦斯 |
| 冻梨 | 梨槽 | `c:foods/fruits/pear` | 果园乐事的梨，别家的梨也行 |

**不影响功能**：酱块、酱渣、酸引水只有本模组有，无法被替代；盐仍走 `c:foods/seasonings/salt`，别家的盐可投。

### 烤架（`GrillRecipes`）

| 配方 | 食材槽 | 调料槽（标签） |
|---|---|---|
| 烤鸡架 | `CHICKEN_FRAME` 专属 | 辣椒油 `c:foods/seasonings/chili_oil` + 糖 `c:sugar` |
| 烤玉米 | `c:crops/corn` | 糖 `c:sugar` |
| 烤油边 | `OIL_EDGE` 专属 | 盐 `c:foods/seasonings/salt` + 辣椒油 `c:foods/seasonings/chili_oil` |
| 烤冷面 | `COLD_NOODLE_SHEET` 专属 | 辣椒酱 `c:foods/seasonings/chili_sauce` + 鸡蛋 `c:eggs` + 糖 `c:sugar` + 醋 `c:foods/seasonings/vinegar` |

**不影响功能**：食材槽本身（鸡架、油边、冷面片）只有本模组有；调料全部换成标签，别家的辣椒油/盐/糖/辣椒酱/鸡蛋/醋都能刷。

### 厨锅（`recipe/cooking/*.json` 等 JSON 配方）

已按原料逐条换成 `{"tag": "c:..."}`，常见映射：

- 原版：`porkchop→c:foods/raw_pork`（**锅包肉三兄弟除外，见下**）、`beef→c:foods/raw_beef`、`chicken→c:foods/raw_chicken`（**小鸡炖蘑菇 / 地锅鸡 / 参鸡汤除外，见下**）、`mutton→c:foods/raw_mutton`、`potato→c:crops/potato`、`carrot→c:crops/carrot`、`egg→c:eggs`、`sugar→c:sugar`、`bread→c:foods/bread`、`iron_ingot→c:ingots/iron`
- 农夫乐事：`wheat_dough→c:foods/dough/wheat`、`rice→c:crops/rice`、`cabbage/cabbage_leaf→c:crops/cabbage`、`tomato→c:crops/tomato`、`onion→c:crops/onion`
- 本模组：作物全部走 `c:crops/...` 或 `c:seeds/...`；调料全部走 `c:foods/seasonings/...`；半成品走 `c:foods/starch`、`c:flours/corn`、`c:foods/vermicelli`、`c:foods/tofu` 等

**不影响功能**：`water_bucket`、`glass_bottle`、`bowl`、`milk_bucket`、`sea_water_bucket` 这些**没有通用标签**的仍按原物品写；`farmersdelight:tomato_sauce`、`fruitsdelight:orange_juice`、`farmersdelight:cooked_rice` 等别家模组专属原料保持原样。

**特例**：三道锅包肉（老派 / 新派 / 橙汁）的猪肉仍然**只能用原版 `minecraft:porkchop`**——猪排是这道菜的灵魂，不能用别家的生猪肉替代。

**特例**：小鸡炖蘑菇、地锅鸡、参鸡汤的鸡肉**只能用原版 `minecraft:chicken`**（生鸡肉）——`c:foods/raw_chicken` 里混着农夫乐事的鸡肉丁，不能用来做这三道菜。小鸡炖蘑菇的蘑菇也从 `c:mushrooms` 改成 `northeast_china_delight:hazel_mushroom` ×2，只能用榛蘑。

### 工作台合成（`recipe/*.json` 顶层合成）

同样已全部换成标签，和厨锅同一张映射表。典型例子：

- `chili_sauce`：红辣椒 `c:crops/chile_pepper` ×2 + 盐 `c:foods/seasonings/salt` + 碗
- `bibimbap`：黄铜碗 + 米饭 + 胡萝卜 `c:crops/carrot` + 鸡蛋 `c:eggs` + 海带（保留 `minecraft:dried_kelp`）+ 辣白菜 `c:foods/kimchi` + 辣椒酱 `c:foods/seasonings/chili_sauce`

### 机械动力（`recipe/{mixing,compacting,milling,sequenced_assembly}/`、`filling/`、`emptying/`）

- `mixing/*`（豆浆、大酱块、辣椒酱、动物油、玉米面、淀粉、粉条）原料已换标签
- `milling/*`（玉米面、花生酱、酸玉米磨水面团）原料已换标签
- `compacting/cold_noodle_sheet`（面团→冷面片）走 `c:foods/dough/wheat`
- `sequenced_assembly/mung_bean_sheet`（淀粉→拉皮）走 `c:foods/starch`
- `filling/*`（流体灌瓶）只用 `glass_bottle`，无标签可换
- `emptying/*`（成品倒回流体）：`soy_sauce`、`vinegar`、`white_vinegar`、`fish_sauce`、`shrimp_paste`、`chili_sauce`、`kvass` 等瓶装品已按 `c:foods/seasonings/...` 换；`soy_milk` 仍用本模组物品（别家的豆浆不能倒成本模组的流体）

### 动力鼓风机风干（`ModFanProcessingTypes`）

- `SOY_MILK` → `DRIED_TOFU` 的判定已从 `stack.is(SOY_MILK)` 改为 `stack.is(ModTags.FOODS_SOY_MILK)`，别家的豆浆也能被吹干。

## 已知的不影响功能点

1. **大缸专属原料**：酱块、酱渣、酸引水、大酱本身只有本模组有，别家无法提供，大缸配方这几格没有标签可换。
2. **烤架食材**：鸡架、油边、冷面片只有本模组有，食材槽不是矿物词典问题。
3. **`emptying/soy_milk_bowl`**：故意保留本模组 `soy_milk` 物品——别家豆浆倒不成本模组的流体。
