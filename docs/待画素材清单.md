> 另外：`临时素材\食材-未更新\` 里是**还没重画的食材贴图**（当前游戏里的版本，按 `食材-<中文名>.png` 命名），
> 可以直接照着重画，画好放回 `临时素材` 顶层我就同步进游戏。

1. 按「文件名」列同名覆盖到对应目录：
   - 物品 → `src/main/resources/assets/dongbei_delight/textures/item/`
   - 方块、液体 → `.../textures/block/`
   - 效果图标 → `.../textures/mob_effect/`
2. 跑一次 `gradlew build`（会把素材同步到开发客户端读取的资源目录）。
3. **不要**用不带 `-Only` 的占位图脚本全量重生成，那会把正式素材覆盖回占位图。
