## 0. 交付规范

| 项目 | 要求 |
| --- | --- |
| 物品路径 | `src/main/resources/assets/dongbei_delight/textures/item/<文件名>.png` |
| 方块路径 | `src/main/resources/assets/dongbei_delight/textures/block/<文件名>.png` |
| 尺寸 | 默认 **16×16**；也可以用 32×32（同一套保持一致即可），程序不限制 |
| 格式 | PNG。物品、植株必须**透明底**（RGBA）；方块不透明 |
| 文件名 | 严格按下表的小写 + 下划线命名，大小写不一致会读不到 |
| 渲染 | 植株走 `cutout`：像素要么全透明要么全不透明，不要羽化、不要半透明描边 |
| 作物画法 | 从贴图**底边往上**画，底部留 1px 空隙，避免插进土里 |
| 动画 | 目前没有任何需要动画的素材 |

**玉米特别说明（两格高）**：

- 下半格用 `corn_crop_stage2/3.png`，上半格是方块 `corn_stalk`（贴图 `corn_stalk.png`）。
- 长到两格高时，**下半格必须是完整一格高的茎秆**，与上半格画面无缝衔接
  （之前出过「上下用同一张图、下半格高度不满，导致上半格看起来悬空」的问题）。
- `stage0/1` 是单格幼苗；`stage2` 开始出现上半格。

## 6. 建议的绘制优先级

1. **大缸 3 张** —— 玩家围着它做泡菜、腊肉、大酱、酱油，最常看到
2. **作物 33 张** —— 地里占视野最多；先画大豆、大白菜、黄瓜、玉米、茄子
3. **常用食材** —— 大豆、大白菜、黄瓜、玉米、盐、大酱、酸菜、腊肉、排骨
4. **料理 11 张** —— 碗装料理统一风格即可
5. **种子、猪副产物、灌肠** —— 出现频率相对低
