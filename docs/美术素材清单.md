> 对应版本：Minecraft 1.21.1 / NeoForge 21.1（仓库主版本）
> 更新日期：2026-09-19（本次按工程里的实际文件全量重排，数量与文件一一对应）

> **只想知道还差哪些图？** 直接看 [待画素材清单](待画素材清单.md) —— 那是一份逐张打勾的工作清单。

目前除「§6 已交付」的 111 张之外，其余素材全部是脚本生成的**开发期占位图**：

- 物品 / 方块物品图标：`tools/generate_placeholder_assets.ps1`
- 作物植株与种子：`tools/generate_crop_files.ps1`
- 液体：`tools/generate_fluid_textures.ps1`
- 界面（JEI 分类背景）：`tools/generate_jei_assets.ps1`

正式美术**同名覆盖**即可生效，不需要改代码、不需要改模型。
注意：交付后请用 `-Only` 点名重新生成占位图（例：`pwsh -File tools/generate_placeholder_assets.ps1 -Only tofu`），
否则不带 `-Only` 的全量生成会把正式素材覆盖回占位图。

## 1. 交付规范

| 项目 | 要求 |
| --- | --- |
| 物品路径 | `src/main/resources/assets/dongbei_delight/textures/item/<文件名>.png` |
| 方块路径 | `src/main/resources/assets/dongbei_delight/textures/block/<文件名>.png` |
| 效果图标路径 | `src/main/resources/assets/dongbei_delight/textures/mob_effect/<文件名>.png` |
| 尺寸 | 默认 **16×16**；也可以用 32×32（同一套保持一致即可），程序不限制。效果图标用 **18×18** |
| 格式 | PNG。物品、植株、效果图标必须**透明底**（RGBA）；大缸 3 张与液体贴图不透明 |
| 文件名 | 严格按下表的小写 + 下划线命名，大小写不一致会读不到 |
| 渲染 | 植株走 `cutout`：像素要么全透明要么全不透明，不要羽化、不要半透明描边 |
| 作物画法 | 从贴图**底边往上**画，底部留 1px 空隙，避免插进土里；同一作物 4 个阶段要能看出「长大」的过程 |
| 碗装料理 | 统一沿用原版碗的造型，只画碗里的内容物，这样一整套菜风格才统一 |
| 液体 | 静止（`_still`）要能上下左右无缝平铺；流动（`_flow`）是竖直方向的流水纹理 |
| 动画 | 目前没有任何需要动画的素材 |

### 2.6 瓶装调料与饮品（11）—— **不需要美术**

这 11 个瓶子（9 个调料 + 动物油 + 格瓦斯）照**原版药水**的方式渲染：模型只有两层 ——
`layer0 = minecraft:item/potion_overlay`（灰白液面，会被染色）、
`layer1 = minecraft:item/potion`（玻璃瓶，不染色），颜色在代码里按物品给
（`BottleColors` 一张表，改数值就能调色）。

所以它们**不用出贴图**；想换成自制外观时，把模型里这两张贴图指到自制素材即可。

对应物品：酱油瓶、醋瓶、酸引水瓶、白醋瓶、鱼露瓶、虾酱瓶、辣椒油、花生酱、植物油。
