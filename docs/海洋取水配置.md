# 海洋取水配置

最后更新：2026-10-13，模组版本 3.0.0。

语言文件中的正式物品名是「海水桶」，注册 ID 为 `northeast_china_delight:sea_water_bucket`。

## 配置

两版本共用通用配置文件 `config/northeast_china_delight-common.toml`：

```toml
[sea_water]
bucket_mode = 1
```

允许值为 1–3，默认 1；修改后重启游戏/服务端应用。多人服以服务端配置决定实际取水结果，客户端建议使用一致的配置。

配置说明以 `config-templates/northeast_china_delight-common.toml` 的用户确认版本为准，两个版本的 `NortheastChinaConfig.java` 保持一致。本次采用用户 2026-10-13 14:11:15 备份中的简短说明，默认模式仍为 1；配置基准用于维护，不能直接覆盖玩家已有设置。

| 值 | 行为 |
| --- | --- |
| 1 | 保留现状。海洋或深海的干净水柱中取水得到独立海水桶；该物品仍只能倒回满足原条件的海洋水柱。 |
| 2 | 取水条件不变，但结果是带海水标记的 `minecraft:water_bucket`。可以像普通水桶一样放水，也能用于本模组海水桶的厨锅和烟熏炉制盐配方。 |
| 3 | 关闭本模组的特殊取水处理；不取消取水事件、不预先移除水源、不覆盖其他模组结果。普通水源按原版得到普通水桶。 |

本功能只控制特殊取水。不会删除已有物品、清空物品栏或注销物品注册 ID；已有海水桶和标记水桶仍能参与配方。模式 2 保留取水所得普通水桶原有的其他物品数据，不强行把其他模组的非普通水桶容器改成水桶。

## 标记与配方

不是把普通水桶整体加入某个物品标签：标记只属于单个 ItemStack，未标记的普通水桶不能用于制盐。

- 1.21.1：独立布尔数据组件 `northeast_china_delight:sea_water=true`，可保存并网络同步。
- 1.20.1：NBT 布尔字段 `"northeast_china_delight:sea_water":1b`。

1.21.1 配方中的海水原料任选示例：

```json
{
  "type":"neoforge:compound",
  "children":[
    {"item":"northeast_china_delight:sea_water_bucket"},
    {
      "type":"neoforge:components",
      "items":["minecraft:water_bucket"],
      "components":{"northeast_china_delight:sea_water":true},
      "strict":false
    }
  ]
}
```

1.20.1 对应的标记水桶原料：

```json
{
  "type":"forge:partial_nbt",
  "items":["minecraft:water_bucket"],
  "nbt":"{\"northeast_china_delight:sea_water\":1b}"
}
```

两条制盐配方沿用原 ID：`northeast_china_delight:cooking/salt_from_sea_water_bucket` 与 `northeast_china_delight:smoking/salt_from_sea_water_bucket`。原料同时允许海水桶和带标记的普通水桶，保持原来的成品与数量。部分匹配不会排斥其他模组附加的名称或物品数据；false 标记及完全没有标记均不匹配。

厨锅使用只接受原料对象的 Ingredient 列表编码，所以任选项使用 `neoforge:compound`，不能直接在 `ingredients` 列表中放嵌套数组。降级脚本将复合原料展开为 Forge 支持的任选数组，再把海水组件原料转为 `forge:partial_nbt`；不能直接写 `forge:compound`，也不能沿用旧的「components 直接去掉、只保留物品 ID」转换，否则配方会加载失败或淡水也会被允许制盐。

标记水桶维持原版物品 ID、贴图、放水与容器行为。倒水时不会把标记存入水流方块；在陆地重新舀起是普通水桶，只有满足海洋特殊取水条件时才会重新获得标记。悬浮提示只对带 true 标记的普通水桶显示，中文简化为「可用于制盐」，英文为「Can be used to make salt」。

## 烧炼制盐与空桶返还

2026-10-13 修复烟熏炉完成制盐后吞掉海水桶或标记水桶的问题。两种桶虽然都声明了空桶容器余物，但原版熔炉家族的烧炼路径只缩减原料数量，不处理原料的合成余物；不能只靠 `craftRemainder` 声明实现返桶。

`mixin/AbstractFurnaceBlockEntityMixin` 仅在成功烧炼独立海水桶或带 true 标记的普通水桶、原料耗尽且原料格为空时，在原料格放回一个全新的普通空桶。不覆盖其他处理已经放入的物品，不复制海水标记；普通淡水及其他原料仍走原流程。无燃料或产物格满时不提前返桶，继续燃烧不会重复生成空桶；熔岩燃料自身返还的空桶仍在燃料格，二者不互相覆盖。

补丁接入原版熔炉家族共用的成功烧炼路径，不额外新增熔炉或高炉配方。1.21.1 的 `burn` 为静态方法，1.20.1 为实例方法，混入签名按 Stonecutter 版本门控切换。
